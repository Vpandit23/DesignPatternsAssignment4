Assignment 4 Instructions
Memento Pattern.
Complete the TODO sections in Board.java, Move.java, both in the assignment04 package and Originator.java in the assignment04memento package.

See the ASSIGNMENT 4 BACKGROUND at the top for more on the notation.
  • You can run the program and make moves by running the program Chessboard.java
  • You can see the game for the Wikipedia page mentioned in the BACKGROUND by running the program Driver.java
  • You can test your program by running the program Assignment04Tester.java. The graphical output should be the graphic "TEST.jpg". The console output should be either testWindows.txt or testMacLinux.txt depending on which computer you are using.
The difference is that the Windows text files end each line with “carriage-return”, then “line-feed”, which is 0D0A in hexadecimal. The Mac and Linux text files end each line with “line-feed”, 0A hexadecimal. We used dos2linux on the Windows version to get the Mac/Linux version in the terminal window of the git-bash tool.
In a Mac or Linux terminal you can use the diff command to check that your file matches the one given.
